# Fresh Listings Saver extension

Load this folder as an unpacked extension in Chrome, Edge, or Brave:

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Select **Load unpacked** and choose this `fresh-listings` folder.
4. Follow `google-apps-script/SETUP.md` once to connect your Drive archive.

Then visit a job detail page on LinkedIn, Indeed, Built In, Glassdoor, Greenhouse, or TrueUp, open the extension, and click **Save to Google Drive**.
