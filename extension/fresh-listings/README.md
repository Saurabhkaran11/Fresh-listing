# Fresh Listings Saver extension

This is the free path for live LinkedIn collection. It runs the LinkedIn public search from your browser, so it is not affected by the hosted site's server connection.

1. Download and unzip `fresh-listings-extension.zip` from Fresh Listings.
2. Open `chrome://extensions` (or `edge://extensions`).
3. Enable **Developer mode**, select **Load unpacked**, and choose the unzipped `extension/fresh-listings` folder.
4. Open the extension, choose a role, location, and time window, then select **Search LinkedIn**.
5. Select the listings you want and choose **Save to Drive**.
6. Follow `google-apps-script/SETUP.md` once to connect the Drive archive.

You can also open any individual job page on LinkedIn, Indeed, Built In, Glassdoor, Greenhouse, or TrueUp and use **Save current job page**.
